# dictionary-follow-inflection

Bypasses a KOReader dictionary (bug?) on Kindle by automatically following inflected word redirects (such as verbs), eliminating the need to tap a second time on the base form.

ONLY FOR BROKEN OR BAD FORMATTING DICTIONARY

On my Kindle/Koreader, no dictionary seems to handle inflected forms correctly. The same dictionaries, however, work fine on Android and on a PC. I don’t understand why, but since they’re the same files and the same Koreader (just for a different platform), it must be a Kindle-specific issue. I don’t know if this also happens with Koreader on Kobo or other e-readers. I’ve experienced this behavior on three Kindle PWs.
This micro-patch automatically follow the correct word to search, so you don’t have to click again to look up the verb’s meaning.
